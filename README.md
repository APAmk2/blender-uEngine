# blender-uEngine
`uEngine` (Also known as `4A Engine`) import/export addon for [Blender](http://www.blender.org/).

## Supported formats
| Extension     | Description           | Can import | Can export  |
|---------------|-----------------------|:----------:|:-----------:|
| .static       | Level sectors model   | Yes        | Yes         |
| .mesh         | Skinned mesh          | Yes        | Yes         |
| .skeleton     | Skeleton container    | Yes        | Yes         |
| .skeleton.lua | Skeleton, but in .lua | Yes        | As .skeleton|
| .m2           | Skeletal actions      | Yes        | No          |
| .model        | Configured models     | Yes        | No          |
